# Vibe Tool Publishing Rules

通用发布规则，不绑定任何具体项目。

## GitHub

- README 优先解释问题和价值，再解释技术。
- 中文优先时提供英文入口。
- 首页至少包含一张清晰截图。
- 推荐展示正常、警告、空状态等关键状态。
- README 负责介绍产品。
- Release 负责介绍版本变化。

## Screenshots

- 首选真实运行截图。
- 缺少状态时，可以制作示意图。
- 示意图需要明确作为展示用途，不伪装成真实日志证据。

推荐状态：

- Normal
- Warning / Error
- Empty / Loading

## Social Media

小红书：

问题 → 为什么做 → 效果 → 使用方式。

视频平台：

痛点 → 演示 → 工作流程 → 结果。

## Core Principles

不要把小工具包装成大型系统。

重点展示：

发现一个真实的小问题，并快速做成可用工具。
